# 나의 단어장 — 설정 가이드

## 구성 파일
- `index.html` — 메인 앱 (표 형태 단어장, 즐겨찾기, 학습모드)
- `api/dictionary.js` — Oxford 사전 API 프록시 (Vercel 서버리스 함수)
- `supabase_setup.sql` — Supabase 테이블 생성 스크립트

## 1) Supabase 테이블 만들기
1. https://supabase.com 로그인 → 예전 IELTS 단어장 앱과 **같은 프로젝트** 사용 (로그인 계정 공유됨)
2. 왼쪽 메뉴 SQL Editor → `supabase_setup.sql` 내용을 붙여넣고 Run
3. `pages`, `words` 두 테이블이 생성되면 완료

## 2) Oxford API 키 — 더 이상 필요 없음
현재 `api/dictionary.js`는 **네이버 영어사전의 비공식 내부 API를 직접 호출(스크래핑)** 하는 방식으로 바뀌었습니다. Oxford API 키 발급 단계는 건너뛰어도 됩니다.

⚠️ **이 방식의 리스크를 꼭 인지하고 사용하세요**
- 네이버가 공식적으로 제공하지 않는 비공식 엔드포인트를 호출합니다. 네이버 이용약관상 자동화된 스크래핑은 금지되어 있어요.
- 네이버가 응답 구조를 바꾸거나 접근을 막으면 예고 없이 동작하지 않을 수 있습니다.
- 트래픽이 많아지면 서버 IP가 일시 차단될 수 있습니다.
- 이 코드는 실제 네트워크 호출 없이(현재 환경 제약) 일반적으로 알려진 응답 구조를 바탕으로 작성됐습니다. **배포 후 실제로 단어를 검색했을 때 뜻이 비어 있다면**, 브라우저에서 https://en.dict.naver.com 에 접속해 개발자도구 Network 탭으로 실제 요청 주소와 응답 구조를 확인한 뒤 `api/dictionary.js`의 `url`과 `items`/`meansCollector` 부분을 그에 맞게 수정해야 할 수 있습니다.
- 예전에 만든 Oxford API 버전(환경변수 `OXFORD_APP_ID`/`OXFORD_APP_KEY` 필요)은 이 방식이 막혔을 때의 대체 수단으로 남겨두는 걸 추천해요.

## 3) Vercel 배포
1. 이 폴더(`index.html`, `api/dictionary.js`)를 GitHub 저장소에 올리기
   - `api/` 폴더 경로가 그대로 유지되어야 서버리스 함수로 인식됩니다.
2. Vercel에서 해당 저장소 Import
3. 환경변수 설정 없이 바로 Deploy 가능 (네이버 스크래핑 방식은 키가 필요 없음)

배포 후 `https://your-app.vercel.app` 접속 → 이메일/비밀번호로 회원가입하면 바로 사용 가능합니다.

## 참고 사항
- 단어 뜻은 **네이버 영어사전을 스크래핑**해서 한글 뜻 그대로 채워집니다 (번역 아님, 네이버가 제공하는 원문 뜻).
- API가 단어를 찾지 못하거나 스크래핑이 실패하면 빈칸으로 남고, 표의 뜻 칸을 직접 클릭해서 수동으로 입력할 수 있어요.
- 즐겨찾기 탭의 "학습모드"는 예전 IELTS 보카 앱의 큐 기반 암기/스펠 방식을 그대로 재사용했습니다.
- 발음은 Google TTS(무료, 비공식 엔드포인트)를 우선 사용하고 실패 시 기기 내장 음성으로 대체됩니다.
